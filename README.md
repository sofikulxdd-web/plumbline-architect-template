# Plumbline

One-page architecture firm website template with a self-drawing floor plan.

Demo: [https://sofikulxdd-web.github.io/plumbline-architect-template/](https://sofikulxdd-web.github.io/plumbline-architect-template/)

A fictional site for a house extension practice. The floor plan draws itself when the page opens.

Plain HTML, CSS and JavaScript in one file, with no build step. It works on phones and respects reduced-motion settings.

More templates: [sofitechllc.com/stores](https://sofitechllc.com/stores/)
